# Activity Project Images

Add any number of `.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif` files to one of these folders:

```text
public/activity-projects/vegwati-hospital-saharanpur/
public/activity-projects/saraswati-vihar-pitampura/
public/activity-projects/elite-fitness-rohini/
```

Run `npm run build` after adding files. The gallery automatically discovers every supported image in the project folder and displays it on that project's Activity detail page.
